cdpgate

Your real browser, driven only by the programs a human has approved, for the profiles and websites they chose.

A leasegate gate for the Chrome DevTools Protocol. There is no debugging port to find.

What it does

  • cdpgate starts your browser with a debugging pipe instead of a port. The gate holds the pipe, so the browser's only automation link is one the gate controls.
  • A program that wants to drive the browser asks the gate. The approval window shows its whole process chain, and the human names the profiles and websites it may reach and for how long.
  • Traffic capture, cookie reading, page printing and form automation tools go through the same gate with the same approval, so one approval covers a working session.
  • Nothing is permanent. Approvals expire, and a refused or expired call says why.

Get it

One file, which installs itself and keeps itself up to date. No administrator rights.

curl.exe -fLo cdpgate.exe https://github.com/cdpai/gate/releases/latest/download/cdpgate.exe
.\cdpgate.exe install

64-bit Windows. Update later from the tray menu, Check for updates. The releases live in the cdpai organisation.
