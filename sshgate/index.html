sshgate

Server SSH keys that no program can read, and a human who sees every login.

A leasegate gate for SSH: an ssh agent whose keys never leave it.

What it does

  • The keys live in sshgate's encrypted vault. sshgate is an ssh agent on its own named pipe, and the private key never leaves it.
  • Each key names the hosts it may be used for. A login anywhere else is refused without a window.
  • Every login goes through the approval window: which process is asking and its whole chain, which host, what command. The human chooses how far up the chain the approval reaches and for how long, and it ends when that process exits.
  • Ordinary ssh keeps working. sshgate writes its own ssh config file, and your ~/.ssh/config includes it with one line. Your own entries are never touched.

Get it

One file, which installs itself and keeps itself up to date. No administrator rights.

curl.exe -fLo sshgate.exe https://github.com/leasegate/sshgate/releases/latest/download/sshgate.exe
.\sshgate.exe install

64-bit Windows. Update later from the tray menu, Check for updates.
