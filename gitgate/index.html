gitgate

git and the GitHub CLI, with the right identity for every folder and no credential lying around.

A leasegate gate for git and GitHub. Tokens and SSH keys stay in the gate; the official git keeps working unchanged.

What it does

  • The official git, unchanged. gitgate setup makes the real git and Windows' own ssh work through the gate. It adds one line to your git config and one to your ssh config, and gitgate setup --undo removes them.
  • Identity by organisation and folder. git picks the account's name and email on its own, from the organisation a remote points at or the folder the repository sits in.
  • Each repository remembers its account. When the sources disagree, or nothing names the repository, gitgate does not guess: it asks the human in the tray, once.
  • Keys and tokens never leave the gate. git over SSH asks the gate's agent to sign, and the GitHub CLI gets a token for one run. A human approves each request after seeing the whole process chain.
  • Guard rails on push. A push to another account's organisation, commits under another identity, and any terms you list as forbidden are refused.

Get it

One file, which installs itself and keeps itself up to date. No administrator rights.

curl.exe -fLo gitgate.exe https://github.com/leasegate/gitgate/releases/latest/download/gitgate.exe
.\gitgate.exe install

64-bit Windows. Update later from the tray menu, Check for updates.
